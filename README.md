# Project REVIVE

REVIVE is a PC version of MX vs ATV Alive. It's built on your PC from your own copy of the game. This page only holds the
downloads; there are no game files here.

## What you need

- Windows 10 or 11, 64-bit
- Your own **MX vs ATV Alive for PS3, US version (BLUS30707)**: a decrypted `.iso`, or the game's folder (the one with
  `PS3_GAME` inside)
- About 10 GB free

## Install

1. Download **Project.REVIVE.Installer.exe** from the [latest release](https://github.com/logan-wurx/project-revive/releases/latest).
2. Run it. Windows warns once because the installer isn't signed: click **More info**, then **Run anyway**.
3. Start Project REVIVE and point setup at your game. The first setup takes about 6 to 8 minutes, once.

## Updates

They're automatic. When you open the game, it checks for a new version and downloads it in the background. The new
version starts the next time you open the game.

## Problems

If the game freezes or crashes, it saves a report in `%LOCALAPPDATA%\Project REVIVE\reports`. Send the newest zip.
