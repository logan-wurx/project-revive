# Project REVIVE

REVIVE is built on your PC from your own copy of the game. This page only holds the downloads; there are no game files
here.

## What you need

- Windows 10 or 11, 64-bit
- Your own licensed copy of the PS3 game, US version (**BLUS30707**)
- About 20 GB free while setup runs. Setup builds the game with many jobs at once, and Windows may grow its page
  file. The finished game uses about 7 GB.

## Install

1. Download **Project.REVIVE.Installer.exe** from the [latest release](https://github.com/logan-wurx/project-revive/releases/latest).
2. Run it. Windows warns once because the installer isn't signed: click **More info**, then **Run anyway**.
3. Start Project REVIVE and point setup at your disc. The first setup takes about 8 to 10 minutes, once.

## Updates

They're automatic. When you open the game, it checks for a new version and downloads it in the background, then
asks **Restart now** or **Later**.

## Problems

If the game freezes or crashes, it saves a report in `%LOCALAPPDATA%\Project REVIVE\reports`. Send the newest zip.
